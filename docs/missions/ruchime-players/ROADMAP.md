## КИРПИЧИ (готовое, переиспользуем)

- **Протокол Kodik воспроизведён на Python без браузера** (этап 2 — готовая
  основа):
  1. `GET https://kodikplayer.com/serial/<id>/<hash>/720p?season=1&episode=<N>&only_translations=…`
     → в HTML `var urlParams = '{…}'` (подписи `d_sign`, `pd_sign`, `ref_sign`)
     и `vInfo.hash` / `vInfo.id` выбранной серии.
  2. `POST https://kodikplayer.com/ftor` (form: `d`, `d_sign`, `pd`, `pd_sign`,
     `ref`, `ref_sign`, `bad_user=false`, `cdn_is_working=true`, `type=seria`,
     `hash`, `id`, `info={}`) → JSON с `links` по качествам; `src` зашифрован.
  3. Расшифровка `src`: сдвиг букв на 18 по классу регистра (ROT18) → base64 →
     `//cloud.solodcdn.com/useruploads/<uuid>/<токен>:<ts>/<quality>.mp4:hls:manifest.m3u8`.
  4. Манифест — обычный HLS, сегменты — обычный TS; проверено: 1280×720.
- **Протокол Vibix/Kinescope расшифрован** (этап 5, стенд
  `scripts/vibix_stand`):
  1. Браузер открывает страницу серии, нажимает `data-player="vibix"` и
     перехватывает запрос `/api/v1/embed-serials/<id>?...&sig=...`.
  2. Ответ — конверт `{"p":"...","v":1}`: строка `p` переворачивается,
     декодируется из base64 и XOR-ится с 32-байтовым ключом.
  3. Ключ не хранится в коде: глобальный кэш `torrent_cache/vibix-key.json`
     (`VIBIX_KEY_STORE`), TTL 12 часов; при истечении или ошибке расшифровки
     ключ восстанавливается из зашифрованного манифеста по известной шапке HLS
     и проверяется расшифровкой ответа API.
  4. Внутри — JSON с сезонами, сериями и ссылками
     `[480p]{RuChiMe}https://...m3u8`; качества 480/720/1080.
  5. Манифест — обычный HLS, сегменты — `.ts` с абсолютными подписанными
     ссылками. `ffmpeg -c copy` качает без браузера; подпись живёт ~12 часов.
- Ссылка с `season`/`episode` выбирает серию на стороне Kodik — referer для
  этого не нужен (проверено: с тем же referer сервер отдавал одну и ту же
  серию, а с `?episode=` — нужную).
- Существующий планировщик умеет выбирать лучшего кандидата на серию из
  нескольких по приоритету качества — новые кандидаты (по одному на плеер)
  вписываются без правок планировщика.
- `sources.video.stream` — готовая точка разрешения потока перед скачиванием
  (сегодня используется для AllVideo).
- `media_items.is_available` — неиспользуемая колонка под признак
  «источник недоступен».

## ТУПИКИ (НЕ повторять)

- **yt-dlp как решение для Kodik/Vibix/Kinescope.** В нём нет экстракторов
  для этих плееров (проверено: `--list-extractors` — 1747 экстракторов, ни
  одного по Kodik/Vibix/Kinescope).
- **Vibix без браузера.** Подпись API (`sig`, `nonce`, `meta`) считает
  обфусцированный SDK; чистым HTTP она не воспроизводится. Браузер нужен один
  раз за запуск — ради подписанного плейлиста, не для сегментов.
- **Vibix «просто отдать m3u8 в ffmpeg».** Манифест Kinescope приходит
  конвертом (`{"p":"…","v":1}`, `content-type: application/vnd.apple.mpegurl`);
  ffmpeg/yt-dlp его не читают, заголовки Origin/Referer не помогают. Перед
  `ffmpeg` манифест расшифровывается стендом.
- **Браузер как загрузчик.** Браузер умеет получить ссылку на поток, но
  сегменты качает `ffmpeg`; браузерная загрузка не нужна ни здесь, ни на
  открытых потоках (Kodik, AllVideo).
- **Выбор серии у Kodik через referer.** Не работает: с двумя referer сервер
  отдал одну и ту же серию. Нужен `?season=&episode=` в ссылке.
- **Разбор всех серий при добавлении.** 387 страниц ≈ 2 минуты (замерено:
  20 серий — 6,2 с) — окно добавления hangs. Разбор ссылки должен читать
  только страницу релиза.
- **Считать каноническую VK-ссылку единственным путём.** Для части роликов
  `vk.com/video…` отдаёт «Access restricted», хотя embed с hash содержит
  рабочий mp4 2160p. Загрузка идёт по `download_url`, а не по канонической
  ссылке; каноническая остаётся идентификатором элемента. Тупик повторён решением Р-63 (единственный вход — вызов страницы
  ролика) и снят решением Р-64.

- **Считать объявленный Vibix-поток рабочим.** Плейлист называет потоки, чей
  манифест CDN отдаёт с 400 (серия 389, 14+ часов). Кандидат проверяется по
  манифесту; без потока — явная ошибка, а не yt-dlp по странице (Р-37).
