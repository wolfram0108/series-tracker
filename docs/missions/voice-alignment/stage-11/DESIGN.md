## Часть 1. Синхронизация — один прогон (сделано, выкачено 2026-11-05)

Прогон открывается с запуском синхронизации и закрывается, когда у каждого исполнителя нет работ сериала
(`work.series.state`, `<владелец>.work.get`). Пока он открыт, сериал занят: таблица допустимого (`Action.EDIT`, `SYNC`)
отказывает в правках сериала, окно их не даёт; раскладка и план — слепок на момент запуска (И-60).

### Допуск правок и слепок
Правку сериала пользователем допускает владелец прогонов (`scan.edit.begin` / `scan.edit.end`), шлюз оборачивает в допуск
каждый путь правки целиком (сохранение карточки вместе с планом папки, источники, рычаги, порядок озвучек, выключение серий,
усыновление). Прогон открывается только после допущенных правок; пока он идёт или открывается, допуска нет. При запуске
прогон снимает правила профилей своих источников и настройки озвучек (`RunSnapshot`), пишет их в свою команду и передаёт
каждому шагу. Прогон закрывается после ответа каждого исполнителя, по последнему посчитанному состоянию (`seq`).

## Часть 2. Контейнер (сделано, выкачено 2026-11-05)

### Итоговое состояние
Файл серии в медиатеке — один MKV под именем из плана: видео основы и звуковые дорожки в порядке озвучек сезона, первая —
«по умолчанию», у каждой — название группы озвучки и язык её озвучки, заданный при создании озвучки (Р-81). Исходники нигде не хранятся: контейнер — единственная копия
между процессами; всё, что нужно для перепаковки, берётся из него самого.

### Кто пишет файл серии
Упаковка `downloads` (`modules/downloads/packing.py`) — шаг прогона синхронизации (`downloads.pack`). Каждая серия — отдельный
процесс (решение владельца 05.11): прогон собирает серии без работ сразу после опроса исполнителей, каждую серию — как только
ни у одного исполнителя не осталось её работы (`WorkState.busy`), при закрытии — серии, чья сборка не удалась, или весь
сериал, если прогон не собирал ничего. Видео основы —
файл победителя слота, дорожки — выложенные озвучками файлы или дорожки старого контейнера. Контейнер складывается рядом
под временным именем `.st-pack.<id>.mkv`, проверяется чтением (`core/container.py`: видео, дорожки, порядок, названия, флаг,
длительность) и одной операцией ставится под имя; затем убираются вытесненные файлы и выложенные дорожки. Старый контейнер
живёт до этой операции. Озвучки получают `voices.tracks.packed` с видео контейнера: запись дорожки следует контейнеру, и при
нетронутом контейнере тоже. В окне такая дорожка — «в контейнере серии».

Дорожка опознаётся по ключу озвучки (метка `ST_DUB`), название — только имя. Файл под именем контейнера, которым слот не
владеет (другой сериал в общей папке, другая строка, ничей файл), не заменяется. Каждая публикация записана в
`pack_publications` до сборки и доводится до конца после остановки; провал упаковки — провал прогона.

### Тождество видео
«То же видео» — тот же источник, плеер и ключ строки раскладки; разрешение не входит. Одна функция в ядре.
Дорожка годна, пока выровнена под видео, тождественное видео контейнера.

### Что делает синхронизация (одно правило: контейнер = функция плана)
| Различие плана и записи о контейнере | Действие |
|---|---|
| порядок или набор озвучек | перепаковка из самого контейнера, без загрузок и конформа |
| новая озвучка | загрузка, конформ под видео контейнера, перепаковка с ней |
| основа — то же видео в другом разрешении | загрузка видео, сборка: новое видео + годные дорожки из старого контейнера; без конформа |
| основа — другое видео | загрузка видео и озвучек, конформ всех под новое видео, сборка; старый контейнер живёт до неё |
| серии нет | загрузка, конформ, сборка |

### Порядок озвучек сезона
Хранится в `composition` (в терминах домена — имена групп). По умолчанию — по порядку добавления: источники в порядке
карточки, внутри источника — по первому появлению. Новая озвучка встаёт в конец и никого не сдвигает; при слиянии групп
общая занимает верхнее из мест; переставляет только пользователь (окно «Выход», уровень сезона, перетаскивание).
Строка списка — «озвучка (1–50)».

### Переход скачанного
Серия, где лежат `.mp4` и `.flac` рядом, при первой своей синхронизации собирается в `.mkv`: видео — из `.mp4`, дорожки —
выложенные озвучки (они выровнены под это видео); после проверки `.mp4` и `.flac` убираются.
