# План: вкладка «Выход» по согласованному макету

Дата: 2026-11-06. Состояние: проект плана, ждёт согласия владельца. Макет:
https://claude.ai/artifact/Qq4USNgQayFH29p1vg76A2 (артборды 1–5).

## 1. Результат

| Что | Требование макета |
|---|---|
| Карточка серии | фон — статус серии; строка 1 — номер и имя выходного файла (на карточке самого малого размера имени нет); строка 2 — источник и разрешение референса `[N] плеер 2160p`; строка 3 — дорожки в порядке контейнера, обводка — дорожка референса; высота постоянная |
| Источник | номер — место в списке источников сериала; цвет — из палитры в 16 цветов, закреплён за источником; одинаково на вкладках «Свойства» и «Выход» |
| Сетка сезона | по дорожкам карточек в ряду может быть: до 6 дорожек — 6, до 12 — 3, до 18 — 2, от 19 — 1, и не больше, чем помещается по ширине; по числу серий сезон хочет: до 12 — 1, до 24 — 2, до 48 — 4, больше — сколько позволяют дорожки; берётся меньшее |
| Шапка вкладки | фильтры с числами; вид «Карточки / Плитки»; «Имена файлов»; расшифровка источников; «Настройки сериала», «Сбросить неудачные попытки», «Синхронизировать» |
| Шапка сезона | полосы «Видео» и «Озвучки» с числами; порядок дорожек контейнера (перетаскивание); «Настройки сезона», «Отключить сезон» |
| Раскрытая серия | под своим рядом; вкладки «Дорожки», «РЕФ» и по одной на группу озвучки |
| Вкладка «Дорожки» | строка на дорожку: место, группа, откуда, статус; действие по состоянию: референс — «Скачать заново», готовая озвучка — «Пересоздать», ошибка — «Повторить» |
| Вкладки «РЕФ» и групп | одна таблица: «Брать», источник, плеер, разрешение, группа (только РЕФ); строки — в порядке, который даёт ядро; перетаскивание меняет порядок, первая отмеченная строка — выбор; галочка во вкладке РЕФ — не брать референсом, во вкладке группы — не брать для озвучки; метка уровня и «как уровнем выше» |
| Настройки сезона и сериала | та же таблица для всего уровня, столбец «Серии»; во вкладке «Дорожки» — счётчики по группам и действия на все серии группы |
| Плитки | для больших сезонов: цвет — статус серии, полоса — цвет источника референса; серия раскрывается тем же блоком |

## 2. Решения

| Вопрос | Решение | Где |
|---|---|---|
| Порядок вариантов | одно правило в ядре, чистыми функциями: очередь референса (разрешение, место плеера в «Порядке источников», место источника в сериале, место строки) и очередь озвучки группы (место плеера, место строки). Выбор референса (`scan`) и план озвучек (`voices`) берут очередь отсюда; окно получает её от владельца рычагов | новый `core/variant_queue.py`; `scan/reference.py` (`RANKING`, `_best`), `voices/planning.py` (`_chain`) переходят на него |
| Рычаги очереди | `reference.order` (без цели, форма «порядок вариантов»: список `{group, source_id, player}`) и `voice.order` (цель — группа, список `{source_id, player}`). Названные варианты идут первыми в заданном порядке, остальные — после них по правилу. Своя очередь серии сильнее удержания референса, как сейчас выбор пользователя | `core/contracts/output_settings.py` (`ValueShape.VARIANT_ORDER`, `LEVER_FORMS`), `composition/levers.py`, `web/src/lib/output.ts` (`RENDERED_FORMS`) |
| Галочка «Брать» | два флага варианта: `reference.allow` (не брать референсом) и `voice.allow` (не брать для озвучки) | там же |
| Снимаемые рычаги | `reference.choice`, `voice.player` (их заменяют очереди: выбор — первая строка), `variant.allow` (делится на два). На проде записей рычагов нет (`output_settings` пуста) — переносить нечего | `composition/levers.py`, потребители в `scan`, `voices` |
| `voice.take` | остаётся: переключатель «Брать озвучку» в шапке вкладки группы. В макете его нет; без него функция пропала бы молча | вкладка группы |
| Удаление источника | из записей-очередей вычищаются только его варианты, запись остаётся | `composition/settings.py` (`sources_of` для формы порядка) |
| Очереди наружу | новый запрос `composition.queues.get {series_id, season?, episode?}` → очередь РЕФ и очереди групп уровня: строки с разрешением, «Брать», уровнем значения, у сезона и сериала — сериями. Считается той же функцией ядра, что у `scan` и `voices`; «Порядок источников» composition спрашивает у `voices.settings.get` | `composition/module.py`, маршрут шлюза, схема API |
| Действия над дорожкой | команды на одну дорожку одной серии. Каждая делает ровно названное действие и сразу ставит эту работу в очередь загрузок; синхронизацию сериала не запускает. Через допуск правки (`scan.edit.begin`), как остальные правки | `voices.dub.retry`, `voices.dub.redo`, `downloads.reference.refetch`; маршруты шлюза; при повторной загрузке референса озвучки серии перевыравниваются по уже существующему пути `reference_downloaded_again` |
| Действия уровня | «Повторить ошибки», «Пересоздать готовые» группы в сезоне — те же команды с охватом сезона и группы | те же команды, поле охвата |
| Цвет источника | колонка `series_sources.color` (0–15). Назначает `catalog` при добавлении — наименьший свободный в сериале. Миграция 0047 раздаёт цвета существующим источникам по `position` | `catalog/repository.py`, миграция, контракт источника |
| Сетка | число карточек в ряду считает окно по правилу раздела 1. Ширину ряда меряет `ResizeObserver` на сетке: медиа-запросов по ширине нет | новый компонент сетки сезона |
| Тексты | ключами каталога `web/src/i18n/ru.ts` | — |

## 3. Шаги

Каждый шаг — отдельный коммит, тесты затронутых модулей зелёные до коммита.

| № | Шаг | Файлы | Проверка |
|---|---|---|---|
| 1 | Правило очереди в ядре; `scan` и `voices` на нём, рычаги прежние | `core/variant_queue.py`, `scan/reference.py`, `voices/planning.py` | перебор перестановок строк серии: без рычагов выбор референса и цепочки озвучек совпадают с прежними; все тесты `scan` и `voices` |
| 2 | Рычаги очереди и два флага вместо трёх старых | `core/contracts/output_settings.py`, `composition/levers.py`, `composition/settings.py`, `scan/reference.py`, `voices/planning.py`, `web/src/lib/output.ts` | наследование списка по уровням; своя очередь серии сильнее удержания; отказ первого варианта ведёт ко второму по очереди; удаление источника вычищает его варианты; тест единого списка форм окна и ядра |
| 3 | Запрос очередей и маршрут | `composition/module.py`, `gateway/api_output.py`, `core/deadlines.py`, `web/src/api/schema.d.ts` | очередь запроса совпадает с выбором `scan` и цепочкой `voices` на тех же данных; сторож сроков |
| 4 | Действия над дорожкой и уровнем | `voices/module.py`, `downloads/module.py`, `gateway/api_output.py` | каждая команда меняет только свою дорожку и ставит ровно её работу; правка вне допуска отказана; несуществующий сериал — 404 |
| 5 | Цвет источника | миграция 0047, `catalog/repository.py`, `catalog/module.py`, контракт, `SourceCard.vue` | бэкап БД перед миграцией; тест миграции на копии; новый источник получает наименьший свободный цвет |
| 6 | Окно | `StatusOutput.vue` и новые компоненты: карточка, сетка сезона, раскрытая серия, таблица очереди, настройки уровня, плитки; `useSeriesOutput.ts`; `ru.ts` | Vitest: правило сетки, порядок и перетаскивание таблицы, галочки, имя файла по размеру; `npm run build` |
| 7 | Полный прогон и живая проверка | — | весь набор тестов двумя половинами под потолком памяти; сторожа; на проде после выкатки (по слову владельца) — сериал 49, серия 11: перестановка РЕФ, снятие галочки, «Повторить» у HORIZON, «Пересоздать» у одной озвучки |

Снимаемые компоненты окна: `OutputLevel.vue`, `OutputLevers.vue`, `OutputEpisode.vue` и их тесты. `VoiceOrder.vue` остаётся.

## 4. Риски

| Риск | Мера |
|---|---|
| Выбор референса после перехода на общее правило поменяется на настроенных сериалах (40, 46, 49) | шаг 1 без смены поведения, доказательство перебором; перед выкаткой — сверка `scan.output.get` до и после на копии прод-БД |
| Очередь, показанная окном, разойдётся с выбором ядра | одна функция ядра для `scan`, `voices` и запроса очередей; тест шага 3 |
| Большие сериалы (655 серий) в окне | вид «Плитки»; раскрытая серия грузит очереди одной серии по запросу |
| Повторная загрузка референса сбрасывает выровненные озвучки серии | так задумано: путь `reference_downloaded_again` уже есть; действие названо «Скачать заново» |

## 5. Остаётся как есть

Отключение серии и сезона; порядок дорожек контейнера; «Синхронизировать»; «Сбросить неудачные попытки» (весь сериал); «Имена файлов»; фильтр отклонений; чтение страниц источников в шапке.
