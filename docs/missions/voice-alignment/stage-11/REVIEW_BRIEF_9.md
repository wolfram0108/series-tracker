## 4. Решения, требующие оценки

| Вопрос | Решение и граница |
|---|---|
| Все ролики серии отказали | лучший по порядку остаётся референсом и повторяется следующей синхронизацией; прогон не крутится по кругу |
| Конечность `_next_source` | проход начинается, только если появились отказы, которых прогон ещё не обходил, и только если сменился победитель хотя бы одной серии |
| Сброс неудачных попыток | правка сериала, а не синхронизация; работа по сброшенным видео и озвучкам — со следующей синхронизацией |
| Две формы кадров потока | `batch` — боевой фронт; `each` — старый фронт `/legacy`; обе строятся из одного генератора ходов |
| Ход — то, что накопилось в очереди к моменту записи | всплеск, опубликованный в одном шаге цикла событий, уходит одним кадром; события разных шагов могут прийти разными ходами |
| Шаблоны подписки остаются в шине | рабочий подписчик их использовать не может (`handle`, поток по таблице); наблюдатели в тестах слушают весь поток |
| Лишний запрос каталога на каждую правку | одно короткое чтение карточки; правило «правка несуществующего сериала — 404» одно для всех маршрутов |
