# Этап 10 — реестр инструментов

> Дата: 2026-11-21. Состояние: актуален. Жанр — реестр.
> Инструмент — всё, что создано для получения информации или проверки: сборщик, анализатор, сторож. Постоянный
> инструмент лежит в `tools/` этой папки и имеет строку здесь; временный удаляется после работы. Инструмент годен к
> применению только со статусом «подтверждён» — после ступеней 0–4 `VERIFICATION.md`; любая правка возвращает
> «не подтверждён». Сырьё — `raw/`, опись — `raw/MANIFEST.md`.

## Сборщики

| Инструмент | Что собирает | Источник | Пишет | Статус |
|---|---|---|---|---|
| `tools/collectors/site_raw.py` | ответы страницы релиза и всех её плееров как пришли: страница, список серий, страницы серий, плееры страницы, каталог Vibix (браузер), плейлист и видео CVH, список Kodik по озвучкам и ответ `ftor`, канал VK (`video.get`, `video.search`) | живые сайты; агенты и заголовки — из кода плееров приложения | `raw/sites/<сайт>__<дата>__<страница>/`, `index.jsonl` | не создан: сырьё снято разовыми прогонами (`raw/run1`…`run5`, опись — `raw/MANIFEST.md`); новые сайты и плееры снимает тот, кто их добавляет |
| `tools/collectors/price.py` | цена одной единицы работы: страница, строка плеера, серия загрузки | живые сайты, стенд | `raw/prices/<дата>.jsonl` | не создан: цена единицы работы — время до сигнала конца чтения, его меряет `stand.py table` (М-2: малый релиз 21,6 с) |
| `tools/collectors/stand.py` | живое чтение страницы источника через изолированный стенд рабочего дерева (свободный порт, новая БД, миграции; для канала VK — копия строк `auth` и `tracker_sessions` только входа VK (`LOGINS`: входы qBittorrent и трекеров стенду не нужны и не копируются) и ключей шифрования источника; процессу стенда задаётся `ST_STAND=1` — без него `ST_READ_RECENT` процесс не принимает): время до сигнала конца чтения, состояние, плееры, строки, группы, ступени, озвучки, число строк для конструктора; печатает `ИЗМЕРЕНИЕ <id>: PASS \| FAIL`; сценарий `series` — стенд на копии настоящей БД (расписание выключено): все сериалы открываются с видом и источниками, видео-сериал удаляется обычным запросом (М-20) | стенд рабочего дерева, живые сайты | `raw/measurements/<id>__<дата>.jsonl`, журнал стенда | подтверждён: запуски М-7 (ruchime), М-8 (dunhuatv), М-9 (канал VK); отрицательный контроль — прежний запуск М-9 без ключей дал FAIL с причиной; копия входа qBittorrent водила стенд в настоящий qBittorrent (HTTP 401, затем 403) — исправлено списком `LOGINS`, проверка копии и целой копии: остаётся только `vk` |
| `tools/collectors/schema_stand.py` | типы API для интерфейса: изолированный экземпляр рабочего дерева, `openapi-typescript` по его схеме в `web/src/api/schema.d.ts`; не трогает работающую систему, в отличие от `npm run gen:api` | рабочее дерево | `web/src/api/schema.d.ts`; строка `SCHEMA_DONE` или `SCHEMA_FAIL` | подтверждён: повторный прогон на неизменённом коде не меняет файл |
| `tools/collectors/frame_pace.py` | темп кадров готовых видео: самая длинная пауза против обычного интервала, по файлу на строку, выборка равномерно по библиотеке | каталог библиотеки | `raw/measurements/PACE__<дата>.jsonl` | подтверждён: три файла для цены единицы, 120 для замера; две проверки разбора вывода в `test_download_integrity` |
