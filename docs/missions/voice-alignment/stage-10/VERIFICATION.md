# Этап 10 — проверка и приёмка

> Дата: 2026-11-01; результаты — раздел 4а (2026-11-02). Жанр — ТЗ на проверку и реестр результатов.
> Что проверяется — требования `SPEC.md` и инварианты `LIFECYCLE.md`. Инструменты проверки — `TOOLS.md`.
> Сырьё прогонов — `raw/` (вне git), опись — `raw/MANIFEST.md`.

## 1. Правила прогона

| Правило | Содержание |
|---|---|
| Прогон | любой запуск, результат которого служит данными для вывода; запускается только через `progon_runner.py exec --predicate <строка итога> --safeguard <с>`; первая строка команды — `# класс: прогон` |
| Предикат | строка итога, которую прибор печатает в любом исходе: `ИЗМЕРЕНИЕ М-<n>: PASS …` или `ИЗМЕРЕНИЕ М-<n>: FAIL …`; у pytest — строка сводки `\d+ (passed\|failed\|error)` |
| Предохранитель | двойная измеренная цена действия (ступень 4½), не больше 180 с; срабатывание — дефект прибора или маркера, прогон не принят и переделывается |
| Больше 180 с | только с согласием владельца на конкретное измерение (`[approval:<tag>]`); такое измерение запускается отдельно и не входит в обычный прогон |
| Вывод | в файл журнала; в доклад — исход, время, строка итога, путь к сырью |
| Сырьё | собирается один раз и не правится; анализ — отдельным чтением сырья |
| Объём | наименьший, дающий ответ: одна серия на живых сайтах; повтор подтверждённой загрузки не делается |

## 2. Ступени

Каждое измерение и каждый прибор проходят ступени снизу вверх; провал любой ступени — исправление и возврат на ступень 0.

| Ступень | Что | Где | Цена |
|---|---|---|---|
| 0 | сборка и импорт: `py_compile` изменённых модулей, `npm run build`, `npm run gen:api`, импорт приборов | рабочее дерево | секунды |
| 1 | чистые функции на образцах с известным ответом: разбор сайтов на сырье `raw/`, `line_of`, раскладка (`composition/project.py`), выбор референса, группы озвучек, покрытие серий склейкой, логика строк интерфейса (Vitest, только `src`) | pytest, Vitest | доли секунды |
| 2 | модуль на поддельной шине: запросы, команды, события, исходы успеха и провала, `on_start` | pytest | секунды |
| 3 | система без сети: настоящие модули на одной шине, сайты заменены сырьём `raw/`; сочетания С-1…С-12 `LIFECYCLE.md` | pytest | секунды |
| 4 | стенд: изолированный экземпляр рабочего дерева, живые сайты, малые релизы, одна серия | приборы `TOOLS.md` | десятки секунд |
| 4½ | цена перед объёмом: одна единица работы на боевом наборе (одна страница, одна серия, один плеер), цена шага — умножением | приборы `TOOLS.md` | секунды |
| 5 | приёмка в интерфейсе: сквозной путь жизненного цикла `SPEC.md`, раздел 6, в браузере | стенд + Playwright | объявляется до запуска |

Тесты разбора сайтов строятся на снятом ответе сайта, а не на придуманной строке. Нет образца в `raw/` — тест
сообщает «нет образца <файл>» и прогон ступени не принимается.
