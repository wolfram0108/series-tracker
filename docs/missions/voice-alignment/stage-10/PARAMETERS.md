# Этап 10 — реестр параметров

> Дата: 2026-11-03. Состояние: актуален. Жанр — реестр.
> Параметр — число или порядок в коде, которого нет в формате, протоколе или условии задачи. Реестр содержит
> параметры, добавленные или изменённые этапом (сверка с `fa9231d` по значению), и для каждого — категорию и
> основание одной фразой. Долгов в реестре нет: у каждого параметра названо, откуда он взят.

## Категории

| Категория | Смысл | Что допустимо |
|---|---|---|
| Формат | величина задана форматом, протоколом или арифметикой | значение, выведенное из источника |
| Измерено | значение получено замером с сырьём | ссылка на замер |
| Предмет задачи | время или порядок — часть требования (ограничение частоты хоста, срок хранения, порядок предпочтения владельца, ограничение обращений к сайту) | величина названа требованием или протоколом хоста |
| Предохранитель | срок, по истечении которого шаг считается неудавшимся; срабатывание — отказ, не «готово» | корректность не зависит от значения: опоздавший ответ добирается сверкой по состоянию |

## Сроки запросов по шине (`core/deadlines.py`)

Срок называет владелец темы, один раз, в таблице ядра; вызывающий числа не называет (сторож `bus_deadlines`). Вложенные сроки
выводятся из внутренних, запрос из неограниченного числа шагов срока не имеет (`scan.series.run`, `scan.series.prepare`).

| Класс | Значение | Основание |
|---|---|---|
| `QUICK_S` | 10 с | чтение или запись одной записи собственного хранилища; замер: 36 тем, самый долгий 0,15 с (проверка пароля), остальные не больше 0,03 с |
| `STANDARD_S` | 30 с | ответ спрашивает соседей или диск; 34 темы, самый долгий 0,02 с; срок темы, которой в таблице нет |
| `SERVICE_S` | 60 с | запись файла, регистрация, внешняя служба; 4 темы, самый долгий 0,02 с |
| `HEAVY_S` | 120 с | обход файлов серии, клиент торрентов, захват потока браузером; самый долгий 0,03 с |
| `FETCH_S`, `RULES_S`, `BATCH_S`, `HANDOVER_S` | 180, 300, 600, 900 с | загрузка файла у трекера, правила по таблице, переименование или регистрация всей серии, приём работы получателем; самый долгий 0,008 с |
| `TABLE_READ_S`, `TABLE_WAIT_S` | 1 800 с, 3 600 с | чтение страницы сайта: 0,42 с на строку у ruchime, 0,14 с у dunhuatv (М-7, М-8), крупнейший релиз около 1 200 строк — около 8 мин, срок вдвое больше; ожидание скана вдвое больше чтения |
| темы с вложенными запросами (`_NESTED`) | собственная работа + сумма сроков шагов | девять тем: `conform.settings.get/set`, `conform.workspace`, `conform.job.get`, `rules.profiles.delete`, `scan.output.switch`, `scan.status.get`, `torrents.db.progress.list`, `voices.settings.set`; сторож `bus_deadlines` читает обработчики и не пускает срок короче суммы |
| `composition.recompute` | 300 с на источник | пересчёт спрашивает правила по разу на источник: срок умножается на число источников серии |
| `composition.preview` | 390 с | сумма трёх шагов подряд: чтение таблицы, правила, группы озвучек |

Замер цены запросов: 2 853 запроса по 90 темам за прогон 1 400 тестов на стенде с малыми данными, самый долгий запрос
0,22 с (`scan.series.run`, без срока). Сроки не равны удвоенной цене: цена на малых данных не несёт ни очереди за последовательным
обработчиком, ни медленного диска боевой базы, и срок вдвое выше цены превратил бы нагруженный сервер в поток ложных отказов.
Срок остаётся предохранителем с запасом не менее 45 раз над измеренным; значение не короче прежнего у любого вызывающего.
