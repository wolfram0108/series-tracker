## РАЗВЕДКА: dunhuatv.ru (проверено 2026-10-28)

| Что | Факт |
|---|---|
| Движок | DataLife Engine |
| Страница тайтла | `/<id>-<slug>-smotret-onlajn.html`; каталог `/page/N/` (94 страницы), лента `/rss.xml` |
| Плеер | один iframe Kodik на весь тайтл: `kodikplayer.com/serial/<id>/<hash>/720p`; рядом виджет агрегатора (`data-title-id` = идентификатор Shikimori/MAL) |
| Метаданные | JSON-LD `sameAs`: Shikimori, MyAnimeList, IMDB; поля «Вышло серий», «Озвучка», «Статус» |
| Озвучки | внутри Kodik: `serial-translations-box`, у каждой озвучки свой `data-media-id` + `data-media-hash` и диапазон серий (`data-episode-count`) |
| Пример | «Практикуя ци сто тысяч лет»: Animy — серии 1–389; AniStar — 287 серий; Студия Константина Исаева — серии 3–60 |
| Качество | Kodik: до 720p |

Не проверено: соответствие нумерации серий Kodik и ruchime для сериалов с
несколькими сезонами; качество и доступность потока каждой озвучки; наличие
в странице способа получить только список серий без Kodik.

## РАЗВЕДКА: track-muxer (по рабочему каталогу, код не виден)

| Что | Факт |
|---|---|
| Назначение | выравнивание озвучки по аудио референса: детект вырезов/вставок и дрейфа, правка, ресемпл до длины референса |
| Контракт метода | строго пара «1 референс + 1 озвучка», `wav` ↔ `wav`, без видео и без стемов; выход — стерео, длина = референсу |
| Метод | `band` (DSP без модели) — основной; `muq` — альтернатива (лицензированная модель) |
| Точность | остаток после сборки: медиана 0,06 кадра (39/39 вырезов, 0 ложных на стенде) |
| Среда | машина пользователя с GPU; рабочий каталог проекта доступен серверу через общее хранилище |
| Прикладной слой | очередь загрузки озвучек (Kodik, Alloha; профиль `copy`, ~480p) и очередь объединения дорожек в контейнер: дорожка = `embedded` / `aligned`, источник, метка, кодек (flac 192), умолчание, покрытие |
| API | описан пользователем, но не виден: адрес, авторизация, эндпоинты, формат входа и выхода неизвестны |

## КИРПИЧИ

- Провайдеры веб-видео: `modules/sources/video_providers/` (реестр, база,
  `StreamUnavailable`, разрешение потока перед скачиванием).
- Протокол Kodik на Python (ROADMAP миссии `ruchime-players`): страница плеера
  → подписи → `POST /ftor` → ROT18 + base64 → HLS; серия выбирается параметрами
  `season` и `episode`.
- Планировщик слотов и замена низкого разрешения высоким: `plan_with_supersession`,
  `media_items.superseded_by`.
- Модуль `downloads`: скачивание через `ffmpeg` по HLS (подходит и для
  аудио-only).
