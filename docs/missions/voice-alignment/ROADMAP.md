## РАЗВЕДКА: track-muxer REST (схема OpenAPI + панель демона, 2026-10-28)

| Что | Факт |
|---|---|
| Адрес | `http://192.168.1.177:8787/`; панель — `/`, схема — `/openapi.json`, `/docs`, `/redoc`, состояние — `/health` |
| Авторизация | не требуется (запросы без заголовков отработали) |
| Среда | `/conform/device`: CUDA, RTX 3090; лимиты: выравнивание — 4 задачи, сборка — 1 |
| Разделы | `projects` / `probe` / `scan` / `downloads` (собственная загрузка с каталогов сайтов), `conform` (выравнивание), `mux` (контейнер), `library`, `settings`, `events` |
| Задача выравнивания | `POST /conform/enqueue`: `ref` (путь), `dubs[]` (пути), `out_dir`, `cache_dir`, `audio_method` (`band` / `muq`), `drift_speed_pct` (0,25–10; по умолчанию 1,25), `fill_silence`, `ref_atrack`, `dub_atracks`, `keep_tmp`, `autostart`, `label`. Одна серия = один референс + набор озвучек |
| Состояние задачи | `GET /conform/jobs/{id}`: `status`, `progress`, `stage`, `ops`, `results[]` |
| Режим | `av` — по видео и звуку (основной; звук один менее надёжен); `audio` — только звук. Видеослой сам исправляет геометрический рассинхрон (кроп, зум, анаморф, полосы) |
| Раскладка (по панели демона) | каталог серии `epNN` содержит файлы озвучек (`<плеер>__rus__<студия>__<качество>p.*`); `out_dir = epNN/_aligned`, `cache_dir = epNN/_conform_cache`; референс — любой путь, в том числе на другом диске; `ref_atrack` / `dub_atracks` — индекс аудиодорожки файла |
| Кэш | `cache_dir` — промежуточные данные серии; `keep_tmp=true` оставляет их после задачи, повторный запуск пропускает декодирование; при `false` кэш удаляется после серии |
| Приёмка | `audio_resid_ms` больше ±80 мс — не сошлось; `critical` — синхронность не гарантирована (остаток, нет общего звука); `suspect` — брак. `fill_silence` заливает тишину на местах вырезов звуком референса |
| Результат озвучки | `DubResult`: `ok`, `mode`, `out_path`, `audio_resid_ms`, `audio_coverage`, `audio_cuts`, `suspect`, `warnings`, `critical`, `error`, `plots` |
| Задача сборки | `POST /mux/enqueue`: сезон; `aligned_root` (каталоги `epNN/_aligned`), `containers_dir` (контейнеры референса), `out_dir`, `tracks[]` (`aligned` / `embedded`, источник, язык, метка, `flac` / `aac`, умолчание) |
| Пути | заданы глазами демона: `/mnt/meganas/media/...`; на сервере то же хранилище — `/nas/...` (по `output_dir` из `/health` и `_pipeline.json`); нужна настройка соответствия |

Исходников демона на сервере нет; контракт определён по схеме и панели. Пробные
задачи не ставятся. Остаётся уточнить по ходу этапов 5–6 (по схеме и панели,
без пробы): имена выходных файлов в `_aligned`, ожидаемые имена каталогов у
`/mux`, поведение при десятках озвучек в одной задаче, отмена и перезапуск
демона.

## РИСКИ ПРОЕКТИРОВАНИЯ

| Риск | Следствие | Решение |
|---|---|---|
| Озвучки одной серии — конкуренты в планировщике слота | Р-37 удалит файлы проигравших озвучек | озвучки хранятся отдельно от видео-кандидатов (CHARTER, «Рамки») |
| Озвучка скачивается с видеорядом, 389 серий × N озвучек | объём хранилища и время загрузки | кэш `_conform_cache` и файлы озвучек очищаются после успешной сборки; лимиты на параллельность |
| Нумерация серий источников расходится (сезоны, склейки) | озвучка выравнивается по чужой серии | сопоставление серий по номеру и длительности до постановки; расхождение — ошибка, а не выравнивание |
| Референс заменён более высоким разрешением | выравнивание устарело | этап 7 |

## КИРПИЧИ

- Провайдеры веб-видео: `modules/sources/video_providers/` (реестр, база,
  `StreamUnavailable`, разрешение потока перед скачиванием).
- Протокол Kodik на Python (ROADMAP миссии `ruchime-players`): страница плеера
  → подписи → `POST /ftor` → ROT18 + base64 → HLS; серия выбирается параметрами
  `season` и `episode`.
- Планировщик слотов и замена низкого разрешения высоким: `plan_with_supersession`,
  `media_items.superseded_by`.
- Модуль `downloads`: скачивание через `ffmpeg` по HLS и `yt-dlp`.
- В демоне `track-muxer` уже есть игроки `kodik`, `cvh` (= `cdnvideohub`),
  `alloha`, `sibnet`, `aksor`; его загрузки озвучек лежат в
  `downloads/<проект>/epNN/<плеер>__rus__<студия>__<качество>p.*`.
