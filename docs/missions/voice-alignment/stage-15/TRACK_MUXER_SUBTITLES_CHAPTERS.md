# Задача для track-muxer: перенос субтитров и глав на шкалу референса

Состояние: сформулирована 2026-11-16, исполнение — владелец track-muxer. Связь с этапом — [DESIGN.md](DESIGN.md), разделы 7.1 и 7.2.

## Зачем

Приложение собирает выходной файл серии из видео референса и дорожек разных источников. Субтитры из файла, чьё видео —
референс, копируются в контейнер как есть. Субтитры из файла, чьё видео не референс, лежат на шкале своего видео; их
время нужно перевести на шкалу референса той же картой, по которой демон кладёт на неё звук. Переносятся любые
субтитры, без потерь. То же — главы файла озвучки.

## Как сейчас (`/openapi.json` демона, 2026-11-16)

| Что | Факт |
|---|---|
| Откуда берутся | только текстовые файлы, лежащие рядом с файлом озвучки (`DubResult.text_tracks`, `TextTrackReport.source`) |
| Дорожки внутри контейнера | не переносятся; задача принимает номера только звуковых дорожек (`ref_atrack`, `dub_atracks`) |
| ASS | векторные рисунки выбрасываются (`dropped_drawings`); позиционирование теряется, у формата выхода его нет (`dropped_settings`) |
| Картинные (PGS, VobSub, DVB) | не переносятся |
| Разбор компиляции (`/conform/reverse`) | субтитров не касается |
| Главы | не переносятся |
| Карта времени задачи | хранится у задачи, через API не отдаётся |

## Требования

| № | Требование |
|---|---|
| Т-1 | Источники субтитров: дорожки внутри файла озвучки (по абсолютному номеру потока, как `TrackProbe.index`) и файлы рядом с файлом озвучки (как сейчас) |
| Т-2 | Виды: текстовые — SRT, ASS/SSA, WebVTT, mov_text; картинные — PGS (`hdmv_pgs_subtitle`), VobSub (`dvd_subtitle`), DVB |
| Т-3 | Переносится только время: время показа каждой реплики (у картинных — каждого набора отображения) переводится картой времени пары озвучка → референс; содержимое — текст, стили, позиционирование, эффекты, векторные рисунки ASS, изображения — не меняется и не перекодируется |
| Т-4 | Формат выхода равен формату входа: ASS остаётся ASS со всеми событиями и стилями, PGS — PGS |
| Т-5 | Реплика, чьё время целиком лежит в отрезке, которого нет в референсе, не пишется; реплика на границе такого отрезка обрезается по границе; обе учитываются в отчёте |
| Т-6 | Ничего не отбрасывается молча: каждая реплика, не перенесённая целиком, учтена в отчёте с причиной |
| Т-7 | Выход: по файлу на дорожку в `out_dir`; отчёт по дорожке — источник (файл или номер потока), формат, файл выхода, реплик на входе и выходе, не перенесено в отсутствующих отрезках, обрезано на границах, ошибка |
| Т-8 | То же для разбора компиляции (`/conform/reverse`): субтитры файла компиляции переносятся на шкалу каждой серии |
| Т-9 | Нынешнее поведение с файлами рядом с озвучкой сохраняется, отчёт по ним — в той же форме, что по Т-7 |
| Т-10 | Главы файла озвучки (и файла компиляции при разборе) переносятся на шкалу референса той же картой: время начала и конца каждой главы; названия и порядок не меняются |
| Т-11 | Глава, целиком лежащая в отрезке, которого нет в референсе, не пишется; глава на границе обрезается по границе; обе учитываются в отчёте |
| Т-12 | Выход глав — файл глав в `out_dir` (формат Matroska), отчёт — число глав на входе и выходе, не перенесено, обрезано |

Предложение по контракту (окончательно — владелец track-muxer): в `ConformEnqueueBody` — `dub_stracks`, параллельно
`dubs`, список абсолютных номеров потоков субтитров каждого файла озвучки; в `ReverseEnqueueBody` — `compilation_stracks`;
в `DubResult` — отчёт по каждой дорожке по Т-7 и по главам по Т-12.

## Проверка

| Проверка | Ожидание |
|---|---|
| Синтетическая пара с известной правкой: из озвучки вырезано 10 с на 60-й секунде, вставлено 5 с на 120-й; субтитры SRT, ASS (с векторным рисунком `\p` и позиционированием `\pos`), PGS | время каждой реплики выхода равно времени, вычисленному по правке, с точностью до кадра |
| ASS после переноса | число событий, стилей и рисунков равно входу за вычетом учтённых в отчёте по Т-5 |
| PGS после переноса | число наборов отображения равно входу за вычетом учтённых по Т-5; изображения побайтно равны входу |
| Реплики в вырезанном отрезке | отсутствуют в выходе, учтены в отчёте |
| Дорожка внутри контейнера озвучки | переносится так же, как файл рядом |
| `/conform/reverse` | субтитры компиляции на шкале каждой серии по тем же правилам |
| Главы той же синтетической пары | время каждой главы выхода равно вычисленному по правке; глава в вырезанном отрезке отсутствует и учтена в отчёте |

## Вне задачи

Упаковка субтитров, шрифтов и глав в выходной контейнер, выбор и порядок субтитров — дело приложения.
