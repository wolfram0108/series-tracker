# Этап 14 — эталон разметки: устройство

Состояние: принято владельцем 2026-11-09 (решения раздела 10 — по предложению), реализовано и выкачено 2026-11-09 (миграция 0056, Р-80). ТЗ дословно — [ЭТАП_14.md](ЭТАП_14.md).

## 1. Термины

| Термин | Значение |
|---|---|
| Эталон разметки (Э) | источник сериала, который владелец пометил эталоном: серии в правильной структуре (заставка, серия, концовка, без вставок), звук на оригинальном языке |
| Строка эталона (M) | строка эталона, данная серии правилами конструктора |
| Шкала серии | строка, на шкале времени которой лежит видео серии (`Video.timeline`); по ней выравниваются все озвучки, она даёт тождество контейнера |
| Картинка (P) | строка, из которой взяты кадры видео серии (`Video.cut_of`); у загрузки без разбора картинка и шкала — одна строка |
| Разбор | задача демона `reverse`: файл картинки + файл шкалы → видео картинки на шкале; чего в картинке нет (края, вырезанное площадкой), берётся из шкалы |

Компиляция этапа 12 — частный случай: P — компиляция, шкала — РЕФ 2. Эталон — второй случай того же разбора: P — лучшая
строка серии, шкала — M. В планировщике разбор один; обобщается `_cut`, нового вида работы нет.

## 2. Демон (проверено по `/openapi.json` 2026-11-09)

`POST /conform/reverse` принимает в `compilation` любое видео. Несоответствия картинки и шкалы (заставки площадки,
реклама, вставки, скорость, вырезанные заставка и концовка) исправляет демон; приложение передаёт запрос и принимает
результат по `ok` и пустому `critical`, как в этапе 12.

| Поле | Значение |
|---|---|
| `compilation` | файл P: загрузка или файл библиотеки |
| `episodes` | `[файл M]` |
| `ref_atrack` | дорожка звука P в её файле: у файла библиотеки — номер собственного звука по тегам, у загрузки — 0 |
| `dub_atracks` | `[дорожка звука M]` |
| `extend_edges`, `audio_method`, `out_dir`, `label` | как в этапе 12 |

## 3. Входы и выбор (чистая функция `core/plan`)

**Входы.** `Choices.markup` — источник эталона сериала или пусто (из `series_sources.markup`). Остальное — как сейчас:
строки, файлы, рычаги, неудачи. Как и всё прочее, входы замораживаются на старте синхронизации: пометка, поставленная во
время прогона, действует со следующего; окну план пересчитывается сразу.

**Строка эталона серии.** M — первая по правилу референса (`reference.order`, `reference.allow`, высота, плеер) строка
источника Э в месте серии, которая: играет; не записана в неудачи загрузки; входит в группу озвучек (озвучка без группы в
работу не идёт, Р-77 — окно говорит, почему эталона у серии нет). Нет такой — у серии нет эталона, она идёт по правилу
без него (этап 12).

**Видео серии с эталоном.** Пути видео, первый открытый по общему правилу ранжирования:

| Путь | Когда есть |
|---|---|
| файл библиотеки на шкале M | библиотека его держит |
| разбор (P, M) | P — строка серии выше M по разрешению: одиночная любого источника или компиляция, в которой стоит серия (членство этапа 12, «выше РЕФ 2» = «выше M»); разбор (P, M) не записан в неудачи |
| загрузка M | всегда, пока M есть |
| файл библиотеки не на шкале M | библиотека его держит |

Ранжирование: сначала «на шкале M» (первые три строки) перед «не на шкале M», дальше — как сейчас (слово пользователя,
высота, плеер, источник, «из равных остаётся то, что есть», место строки). Файл не на шкале M выбирается только когда ни
один путь на шкале M не открыт — так прежний файл не теряется, пока замена не сделана.

**Файл картинки.** Если библиотека держит загрузку той же строки P (не разбор) не ниже по высоте, разбор берёт файл
библиотеки, а не качает P заново. Иначе P качается целиком.

**Звуки.** Собственный звук видео разбора — звук P (её озвучка). Звук M — оригинальная дорожка, **всегда последняя** в
контейнере, вне порядка озвучек сезона; у загрузки M это её собственный звук. Звук строки, которая и есть шкала серии,
синхронен с видео по построению: он берётся из файла шкалы (загрузка этой синхронизации или контейнер библиотеки) — без
отдельной загрузки и без конформа.

## 4. Тождество

| Положение | Следствие |
|---|---|
| Видео на шкале M (разбор или загрузка M) | тождество контейнера — тождество M; дорожки, выровненные по M, годны для любой картинки |
| Смена картинки на той же шкале | перепаковка: дорожки берутся из старого контейнера как есть |
| Смена шкалы (пометка, снятие, перенос, другое видео за строкой M) | дорожки выравниваются заново из контейнера или из загрузки (этап 8) |

## 5. Жизненные циклы

### 5.1. Серия: состояния

Состояние серии — функция входов, не хранимый флаг: его даёт план.

| Состояние | Видео контейнера | Звуки |
|---|---|---|
| Без эталона | как сейчас (этап 12) | как сейчас |
| Эталон — сама картинка | загрузка M | озвучки по порядку сезона, звук M последний |
| Разбор | P на шкале M | звук P на месте его озвучки по порядку сезона, озвучки по порядку, звук M последний |
| Ждёт разбора | прежний файл (любой шкалы) | прежние; новое применяется группой целиком, когда все её шаги удались |

### 5.2. События и что делает следующая синхронизация

| № | Событие | Что меняется в плане | Работа |
|---|---|---|---|
| С-1 | Пометка Э, у серии есть P выше M | шкала → M; путь — разбор (P, M) | загрузка M; P — файл библиотеки или загрузка; разбор; озвучки выравниваются по видео разбора: из загрузки строки или из прежнего контейнера (он — источник звука, картинка и дорожки в нём синхронны); сборка: звук P по порядку, звук M последний; прежний файл уходит, когда в цели живёт всё из него |
| С-2 | Пометка Э, выше M ничего нет | путь — загрузка M | загрузка M, озвучки выравниваются по ней; прежний файл уходит по тому же правилу |
| С-3 | Пришла строка выше нынешней P (или выше M у С-2) | разбор (P′, M) лучше по высоте | загрузка P′, разбор, перепаковка; дорожки как есть (Э-6) |
| С-4 | Загрузка M не удалась (записано) | у серии нет эталона | правило без эталона; держимое на шкале M остаётся, пока лучшее не сделано |
| С-5 | Загрузка P не удалась (записано) | следующая P по правилу | то же для следующей; в конце — загрузка M |
| С-6 | Демон отказал в разборе или нашёл `critical` (записано `("cut", P, M)`) | следующая P, в конце — загрузка M | то же; загрузка M этой синхронизации берётся снова, а не качается вторично (см. п. 6, «загрузка по строке») |
| С-7 | Сбой момента: сеть, демон недоступен, ответ не пришёл | ничего не записано | группа серии не применяется, файл прежний; следующая синхронизация повторяет |
| С-8 | Синхронизация остановлена и продолжена после старта | — | задача разбора находится по ключу (`conform.job.find`), как в этапе 12 |
| С-9 | Пометка снята | у серий нет эталона | видео на шкале M остаётся: загрузка P на своей шкале той же высоты не лучше («из равных остаётся то, что есть»); звук M становится обычной озвучкой — порядок сезона |
| С-10 | Пометка перенесена на Э′ | шкала → M′ у серий, где M′ есть | как С-1: разбор заново; картинка из прежнего разбора не берётся (у разбора своя шкала) — P из загрузки или из файла библиотеки, если он её загрузка; звук M — обычная озвучка, выравнивается по M′ |
| С-11 | Источник Э удалён из сериала | пометка уходит с ним | как С-9 |
| С-12 | Строка M пропала из чтения (офлайн) | у серии нет эталона | как С-9: держимое остаётся, звук M в контейнере — как есть |
| С-13 | За строкой M другое видео (площадка перезалила) | другая строка — другая шкала | как С-10 |
| С-14 | Пропала P (офлайн), разбор в библиотеке | — | держимое на шкале M остаётся: файл библиотеки — первый путь |
| С-15 | «Удалить» видео разбора | видео уходит только ради другого видео серии | следующий путь по правилу; по общему правилу «Удалить» удалённое делается заново, если путь к нему открыт |
| С-16 | Рычаги референса серии, сезона, компиляции | выбор M внутри Э и порядок картинок | только план; работа — когда выбор меняет путь |
| С-17 | Серия выключена | — | ничего нового (как сейчас) |
| С-18 | Компиляция охватывает серию и выше M | P-кандидат наравне с одиночными | разбор компиляции по M; шкала у всех серий компиляции — M |
| С-19 | Серия частями у одного из источников | разбор частей нет (как в этапе 12) | части — свои места; эталон действует там, где у места есть M |
| С-20 | Сброс неудачных попыток | записи С-4…С-6 уходят | следующая синхронизация пробует снова с лучшего пути |

### 5.3. Файлы и дорожки

| Что | Где живёт | Когда уходит |
|---|---|---|
| Загрузка M, загрузка P | папка загрузок синхронизации | конец синхронизации (как все загрузки) |
| Копии файлов для демона, кэш | папка задачи | конец задачи (как сейчас) |
| Выход разбора | папка задачи → сборка контейнера | папка — вместе с записью задачи в истории демона |
| Звук M | контейнер, дорожка строки M, выровнена по M | по общему правилу дорожек (выключение озвучки, «Удалить») |
| Прежний файл серии | библиотека | когда всё из него живёт в цели; иначе остаётся скрытым (`.off`) |

Звук M попадает в контейнер в той же синхронизации, где скачана M: после неё загрузки нет, и звук живёт только в
контейнере.

## 6. Попутные классы (вскрыты разбором, входят в этап)

| Класс | Сейчас | Решение |
|---|---|---|
| Звук шкалы выравнивается к самому себе | при разборе компиляции звук РЕФ 2 качается второй раз (до 720p) и идёт на конформ к видео, лежащему на его же шкале | звук строки шкалы — из файла шкалы, без загрузки и конформа |
| Шкала качается урезанной | РЕФ 2 качается до 720p (`OTHER_MAX_HEIGHT`): «только показывает, где резать», но при `extend_edges` края картинки берутся из него | файл шкалы даёт картинку краёв и звук — качается целиком |
| Одна строка качается дважды за синхронизацию | загрузка названа ролью (`ref2:…`, `video:…`): после неудачного разбора та же строка, ставшая видео, качается снова | загрузка названа строкой и высотой: роль не меняет шага |
| Звук картинки-файла не указан демону | `ref_atrack` не передаётся | номер собственного звука по тегам контейнера |
| Компиляция-озвучка качается для каждой серии | загрузка озвучки названа местом серии (`dub:{серия}:{строка}`): компиляция, озвучивающая несколько серий, качалась столько же раз (нашёл инвариант Э-7) | загрузка озвучки названа строкой; общий шаг без серии |
| Сбой общего шага не виден в окне | сбой загрузки компиляции (шаг без серии) не попадал ни в одну серию | сбой общего шага показывается каждой серии, которая его ждёт |
| Окно не знает видов дорожки плана | контракт окна (`PlanGoalTrack.kind`) перечислял три вида: новый вид рвал ответ окна (нашла приёмка в браузере) | вид `timeline` в контракте; модель мира проверяет ответ окна по контракту на каждом шаге случайных историй |
| Собственный звук разбора в окне — звук шкалы | ячейка собственного звука файла сопоставлялась по группе шкалы, звук картинки показывался отсутствующим | у картинки разбора в ответе окна — её группа (`CutPicture.voice_group`); собственный звук — по ней |

## 8. Инварианты

| № | Инвариант |
|---|---|
| Э-1 | У сериала не больше одного эталона |
| Э-2 | Видео серии с M лежит на шкале M, кроме случая, когда ни один путь на шкале M не открыт (тогда — прежний файл) |
| Э-3 | Видео на шкале M — разбор, только когда P выше M; иначе это загрузка M |
| Э-4 | Звук строки шкалы в контейнере — из файла шкалы, без конформа |
| Э-5 | Пока эталон действует, звук M — последняя дорожка контейнера |
| Э-6 | Смена картинки на той же шкале не перевыравнивает ни одной дорожки |
| Э-7 | Ни одна строка не качается дважды за синхронизацию |
| Э-8 | Пометка, снятие и перенос не теряют ни одного звука: что было в контейнерах, живёт в цели или остаётся в скрытом файле |

## 9. Проверка

| Что | Чем |
|---|---|
| Выбор и события С-1…С-20 | перебор сочетаний в тестах планировщика: высоты M и картинок, компиляция поверх, неудачи загрузки и разбора, офлайн M и P, пометка ↔ снятие ↔ перенос, порядок событий; после каждого шага — инварианты Э-1…Э-8 |
| Порядок звуков | модель мира проверяет порядок всех звуков каждого видимого файла |
| Запрос к демону | тело `conform.reverse` для одиночной картинки и файла библиотеки; модель демона на стенде отвечает по нему |
| Окно | приёмка в браузере на стенде: пометка, синхронизация, контейнер с разбором и последней оригинальной дорожкой, снятие пометки |
| Живая проверка | одна серия сериала 40: ПВА 2160p — картинка, эталон — источник владельца |

## 10. На решение владельца

| № | Вопрос | Предложение |
|---|---|---|
| 1 | В источнике-эталоне у серии несколько строк (плееры, озвучки) | M — первая по правилу референса среди строк источника; пометка — на источнике, как сказано в ТЗ |
| 2 | Звук M после снятия пометки | остаётся обычной озвучкой по порядку сезона (С-9) |
| 3 | Шкала качается целиком (п. 6) — меняет и разбор компиляций | края разбора в полном разрешении шкалы |
