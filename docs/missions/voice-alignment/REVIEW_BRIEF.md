# ТЗ на внешнее ревью: многодорожечная обработка сериалов

Дата: 2026-10-29. Состояние: актуально. Заменяет: —.

## 1. Предмет и цель

**Система.** `series-tracker` — медиа-сервер отслеживания, загрузки и нарезки сериалов. Один процесс
`asyncio`: «тупая» шина (публикация и подписка с масками) и модули, общающиеся конвертами
(событие, команда, запрос, ответ). Единственная HTTP/SSE-точка — модуль `gateway`; фронтенд —
Vue 3 + TypeScript + PrimeVue.

**Предмет ревью.** Возможность «сериал с несколькими озвучками». Сайт-витрина (`dunhuatv.ru`: плееры
CVH и Kodik) отдаёт одну серию в нескольких озвучках. Выбирается референс — озвучка, чьё видео остаётся
в медиатеке. Остальные озвучки серии скачиваются во временный каталог (не выше 720p, с запасными
источниками), выравниваются по референсу внешним сервисом выравнивания (HTTP/SSE-демон) и кладутся
рядом с видео как внешние аудиодорожки в именовании Jellyfin. Состояние каждой озвучки видно в карточке
серии.

**Цель ревью.** Оценить код этапов 0–9 на соответствие требованиям среды и проекта (раздел 4) с упором
на качество модульности и расширяемости (раздел 5). Искать дефекты **класса**, а не частности.
