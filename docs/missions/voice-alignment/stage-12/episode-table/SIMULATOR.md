# Симулятор планировщика таблицы серии

Дата: 2026-11-08. Состояние: работает; модель — [MODEL.md](MODEL.md).

## 1. Назначение

Предсказать поведение планировщика до того, как он управляет файлами: прогнать через него любые ситуации на таблицах и
закрывать вопросы модели по тому, что он делает, а не по описаниям.

## 2. Состав

| Часть | Где | Что делает |
|---|---|---|
| Таблицы | `core/plan/tables.py` | Онлайн-строки серий после правил, актив (контейнер: видео, дорожки, слепки, по какому видео выровнены, родители вырезанного видео), выбор пользователя |
| Планировщик | `core/plan/planner.py` | Чистая функция: из таблиц и приоритетов — цель каждой серии, граф операций, группы применения (что остаётся, собирается, уходит, скрывается, теряется по команде) |
| Мир | `tests/plan_world.py` | Исполняет граф без настоящих файлов. Знает истинные сезон и серию за каждым видео: выравнивание удаётся, только если озвучка и видео — одно и то же. Аварии задаёт сценарий: сбой чтения; загрузка не удалась навсегда или на один раз; ответы выравнивания «не совпало», «критичная находка», «подозрительно, принято», «ответ потерян»; разбор с критичной находкой или без ответа; файл пропал с диска |
| Хаос | `tests/plan_world.py`, `Chaos` | Случайные изменения и аварии по одной на шаг: новые строки, пропажа строк, неверные номера, пересечение номеров, другой сезон, сдвиг нумерации целого источника, подмена видео под строкой, видео выше; включение и отключение серий, групп, компиляций; ручной порядок референса; перестановка порядка озвучек; «Удалить»; все аварии мира и сброс неудач. В конце истории аварии прекращаются, и сериал обязан успокоиться |
| Синхронизация мира | `tests/plan_world.py`, `World.sync` | План от среза; неудачные попытки записываются, план пересчитывается от того же среза, пока новых неудач нет; применение — один раз в конце |
| Проверки | `tests/plan_world.py`, `World.check`, `World.settle` | После каждой синхронизации: план — функция входов; в каждом файле дорожки — та же серия, что видео; дорожки выровнены по видео своего контейнера, одна дорожка на озвучку, свой звук не дублируется; один видимый файл на серию; ничто не уходит без замены, кроме «Удалить»; свой звук ушедшего видео живёт дальше; не применённая группа не трогает файлы; после полной синхронизации план пуст. После аварий — сериал успокаивается за несколько синхронизаций |
| Мир на диске | `tests/plan_disk.py`, `tests/test_plan_disk.py` | Тот же план на настоящих файлах. Каждый ролик — маленький файл ffmpeg; что он на деле (сезон и серия) — в его содержимом: цвет кадра и тон звука. Сайт — HTTP-сервер с роликами, качает настоящий загрузчик сервиса (`modules/downloads/ytdlp`). Демон выравнивания — модель на протоколе настоящего (те же адреса, тела, схема полей, задачи, результаты, `dub_atracks`, разбор компиляции); с ней говорит настоящий клиент сервиса (`DaemonClient`); озвучка ложится на видео, только если её звук — серия картинки. Контейнер собирает настоящий `core.container.build` со вложением слепка. Применение — по журналу: обрыв процесса до журнала или на любом его шаге, перезапуск доводит журнал или оставляет срез. В начале синхронизации таблица актива сверяется с диском. Проверки: файлы библиотеки — ровно таблица; в каждом файле картинка и каждый звук декодируются в одну серию; вложение каждого файла — его строка таблицы; актив, восстановленный из одних вложений, — таблица |
| Перебор | `tools/checks/plan_fuzz.py` | Тысячи историй хаоса на маленьком сериале двух сезонов и истории хаоса на мирах настоящих сериалов |
| Сценарии | `tests/test_plan_simulator.py` | Ситуации модели, аварии по одной и 150 историй хаоса |
| Настоящий сериал как таблицы | `tools/checks/plan_real.py` | Копия базы сервиса; раскладка настоящим конструктором — таблицы страниц через правила профилей и группы озвучек теми же функциями, что у сервиса (можно подставить другие правила); актив из файлов и дорожек; выбор пользователя; правило имени сериала |
| Что планировщик сделал бы сейчас | `tools/checks/plan_on_series.py` | Отчёт по сериалу и строка о совпадении раскладки с сервисом. Отчёт — вне git |
| Ситуации на настоящих сериалах | `tools/checks/plan_situations.py` | Мир из настоящего сериала, истина — нынешние номера; ждущая работа выполняется, затем на каждую ситуацию — синхронизация и проверка инвариантов. Отчёт — вне git |

## 3. Сценарии

| Сценарий | Что показывает |
|---|---|
| Референс и три озвучки перенумерованы в серию 6 | Серия 6 берёт видео и три дорожки как есть; серия 5 качает новый референс и 16 озвучек, офлайн-озвучку выравнивает из прежнего контейнера; прежний файл уходит после всех преобразований |
| То же, но у серии 6 есть своя озвучка | Видео на деле серия 5: выравнивание озвучки серии 6 к нему не удаётся; неудача записана, план пересчитан без неё, остальное применено |
| Источник забыл референс | Работы нет |
| Вышел лучший референс | Онлайн-озвучки качаются заново, офлайн выравнивается из прежнего контейнера |
| Та же строка в большем разрешении | Загрузка видео, дорожки берутся как есть |
| «Удалить» у онлайн-референса | То же видео скачивается заново, дорожки берутся как есть |
| «Удалить» у офлайн-референса | Следующее видео; офлайн-озвучка — выравниванием из прежнего контейнера |
| «Удалить» референса, у серии нет ни одной онлайн-строки | Дорожки уходят вместе с видео, план называет их |
| Серия отключена и включена | Файл скрывается и возвращается без работы |
| Группа отключена, потом сменился референс | Дорожка остаётся и выравнивается заново из прежнего контейнера |
| Подмена видео под той же строкой | Той же высоты — ничего; выше — загрузка |
| Сбой загрузки | В той же синхронизации берётся следующий источник |
| Озвучка не выравнивается к новому видео ни одним путём | Новый контейнер без неё; прежний файл, где она одна живёт, остаётся скрытым; после сброса неудач она выравнивается, прежний файл уходит |
| Референс оказался другой серией (9 из 10 озвучек не выравниваются), правило исправлено | Видео уходит в свою серию и становится там референсом; её озвучки выравниваются к нему, прежний референс уходит; серия, откуда видео ушло, выбирает другое видео, её озвучки выравниваются к нему заново |
| Серия перенумерована сознательно | Файл переезжает с дорожками как есть; выравнивается только новая озвучка |
| Два видео с одним номером, неверное стоит первым | Все озвучки к нему не выравниваются: файл держит одно видео, неудачи записаны, больше ничего |
| Серия ушла в другой сезон | Файл переезжает с дорожками как есть |
| Весь источник сдвинут на серию | Видео переезжают, озвучки не выравниваются к чужим видео и выравниваются к своим; сериал успокаивается |
| Файл пропал с диска | Видео и онлайн-озвучки делаются заново; офлайн-озвучка, жившая только в этом файле, утрачена — это потеря вне сервиса |
| Ответы выравнивания | «Подозрительно» — принято; «критично» и «не совпало» — записано, озвучка не входит, прежний файл держит её дорожку; «ответ потерян» — группа ждёт, следующая синхронизация доводит |
| Порядок озвучек меняется раз за разом | Только пересборка, ни одной загрузки и выравнивания |
| Включения и отключения туда-обратно | Ни одной загрузки и выравнивания |
| Разбор с критичной находкой | Серия берёт одиночное видео |
| Сбой чтения источника | Работы нет |
| Разбор компиляции, у компиляции сменилась группа | Нового разбора нет |
| «Удалить» дорожки онлайн-озвучки | Дорожка скачивается заново |

## 4. Найдено симулятором и исправлено в модели

| Что | Исправление |
|---|---|
| Из нескольких файлов одного видео бралось первое по имени: скрытый остаток или файл ниже разрешением — и серия собиралась заново на каждой синхронизации | Видео представляет лучший файл: выше разрешением, затем файл серии, затем не отключённый |
| Скрытый остаток и отключённая серия получали одно имя `… .mkv.off`; отключение серии записывалось поверх остатка, и его дорожка терялась | Скрытый остаток получает своё имя `… .hidden-N.mkv.off` |
| Дорожка группы, совпадающей со своим звуком нового видео, держала прежний файл скрытым | Свой звук видео считается заменой дорожки той же группы |
| Новое видео серии получало имя прежнего файла другой серии; две группы применялись врозь, и вторая удаляла по имени новый файл первой | Серия, чья цель пишется туда, где лежит файл, — в одной группе с ним |
| Компиляция вышла в большем разрешении — нового разбора не было | Вырезанное видео ниже компиляции — кандидат на новый разбор, как та же строка в большем разрешении |
| Свой звук видео (у вырезанного — озвучка компиляции) терялся при замене видео | Свой звук — актив, как дорожка: берётся как есть или выравнивается из прежнего контейнера по номеру дорожки |

## 6. Ситуации на настоящих сериалах (2026-11-08)

Раскладка настоящего конструктора, запущенного по копии базы, совпала с раскладкой сервиса по всем пяти сериалам
(3173, 7193, 365, 446 и 418 строк). Ситуации — на мире, где ждущая работа уже выполнена; во всех инварианты держатся.

| Ситуация | Что вышло |
|---|---|
| Источник удалил все видео (каждый источник каждого сериала) | Работы нет; файлы и дорожки остаются |
| Удалено правило профиля (каждое правило каждого профиля) | Только то, что правило меняет: правило исключения или диапазона открывает новые серии (сотни загрузок); правило группы делает строки другой озвучкой, и она добавляется дорожкой; ни одного удаления |
| Номер строки референса сменён на следующий | Неудачи выравнивания озвучек следующей серии к чужому видео записываются, план пересчитывается, применяется то, что удалось; то, что некуда деть, остаётся скрытым; если у следующей серии своё видео лучше — перенумерованное видео уходит как заменённое, прежняя серия качает новый референс |
| Серия отключена; группа отключена | Работы нет |
| «Удалить» у видео | То же видео скачивается заново, дорожки как есть; у вырезанного видео — компиляция скачивается и разбирается заново |
| Вышел референс выше | Видео и онлайн-озвучки серии качаются заново, прежний файл уходит после сборки |

## 10. Чего модель симулятора пока не держит

| Что | Где сказывается |
|---|---|
| Правило конструктора как действие хаоса | хаос меняет номера и сезоны строк напрямую; удаление правил настоящим конструктором — в ситуациях на настоящих сериалах (`plan_situations.py`) |
