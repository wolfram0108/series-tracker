# Этап 12 — компиляция как референс: устройство

Состояние: проект на согласовании, 2026-11-07 (вариант 3: компиляция — уровень для набора серий; цвет, буква и обводка из ячеек). ТЗ дословно — [ЭТАП_12.md](ЭТАП_12.md).

## 1. Термины

| Термин | Значение |
|---|---|
| Компиляция | строка раскладки, у которой одно видео охватывает несколько серий (`episode_end > episode_start`) |
| РЕФ 1 | компиляция, выбранная референсом серии |
| РЕФ 2 | одиночная серия, по которой демон находит серию внутри компиляции; без компиляции она сама референс |
| Разбор | задача демона вида `reverse`: компиляция + РЕФ 2 → видео серии из компиляции на шкале времени РЕФ 2 |

## 2. Демон: разбор компиляции (контракт проверен на живом демоне 2026-11-07)

| Что | Факт |
|---|---|
| Постановка | `POST /conform/reverse` {`compilation`, `episodes[]`, `extend_edges` = true, `out_dir`, `keep_tmp`, `label`, `audio_method`, `drift_speed_pct`, `autostart`, `ref_atrack`, `dub_atracks`} → список задач, по одной на серию |
| Кэш | компиляция готовится один раз на партию, в кэше папки `out_dir`; партии с одной `out_dir` делят его |
| Результат | `<out_dir>/<папка серии>/<серия>.mkv` — видео на шкале серии: картинка и звук компиляции там, где они совпали с серией |
| Края | `extend_edges` = true: начало и конец, которых нет в компиляции, берутся из самой серии; false: результат обрезан по компиляции |
| Имя задачи | `label` задачи разбора = имя папки серии |
| Итог пары | `ok`, `out_path`, `from_ref_s` (секунд из компиляции), `from_dub_s` (секунд из серии), `suspect`, `critical`, `warnings`, `error`; `assigned_pct` для разбора не мера |
| Вид задачи | `ConformJob.kind`: `episode` (озвучки на референс) или `reverse` (разбор) |
| Просмотр каталога | `GET /conform/reverse/scan?episodes=…&out_dir=…` — серии каталога, файл каждой, готов ли результат |

## 3. Правило: компиляция — уровень для набора серий

Компиляция — уровень настроек между сезоном и серией: сериал → сезон → компиляция → серия. Запись о ней хранится в
терминах домена (источник, плеер, группа озвучки, сезон, диапазон серий), чтобы пережить новое чтение таблицы.

1. **Членство.** Серия стоит не более чем в одной компиляции. Включение серии в компиляцию выключает её в той, где она
   стояла. Выключение серии в её компиляции оставляет её ни в одной: референс — РЕФ 2.
2. **По умолчанию** (выбора пользователя нет) серия стоит в самой короткой по охвату компиляции, которая её охватывает,
   играет, не выключена целиком и выше по разрешению, чем РЕФ 2 серии. При равном охвате — выше разрешение, затем порядок
   источников. Такой компиляции нет — серия не стоит ни в одной (свой референс не хуже).
3. **Компиляция не выше РЕФ 2** в серию не включается: отказ `not_allowed`, выключатель в окне недоступен.
4. **Выключенная целиком компиляция** не кандидат: её серии идут по правилу 2 в следующую.
5. **РЕФ 2** — одиночный референс по действующему правилу (очередь «РЕФ», рычаги `reference.order`, `reference.allow`,
   переход к следующему видео при неудачной загрузке). Порядок задаётся на уровне компиляции для всего набора; у серии —
   свой поверх него.
6. **Нет РЕФ 2** — разбирать не по чему: серия не стоит ни в одной компиляции, отметка `unfit`, как сейчас.
7. **Разбор не удался** — референс серии временно РЕФ 2, разбор в состоянии «ошибка» с кнопкой «Повторить»; членство не
   меняется само.

Рычаги: `compilation.member` (уровень серии: компиляция или «ни в одной»), `compilation.off` (уровень компиляции),
`reference.order` и `reference.allow` на уровне компиляции. Выбор — чистая функция в `scan/reference.py`.

## 4. Тождество видео и дорожки

| Положение | Следствие |
|---|---|
| Разбор с `extend_edges` = true даёт видео на шкале РЕФ 2 той же длительности | тождество видео разбора = тождество РЕФ 2 (`core.container.identity`: источник и строка) — то же правило, что для другого разрешения того же видео (ЭТАП_11, п. 5) |
| Дорожки выровнены по РЕФ 2 | годны для видео разбора; смена РЕФ 1 ↔ РЕФ 2 — перепаковка без конформа |
| Смена РЕФ 2 | другое тождество: дорожки делаются заново (этап 8) |
| Новая серия | сначала разбор, затем конформ озвучек по видео разбора |

## 5. Поток работ серии (один прогон синхронизации)

```
скан ── выбор: РЕФ 2 + РЕФ 1 ──┬── downloads: РЕФ 2 в библиотеку (как сейчас, in_plan_single)
                               └── voices: файл компиляции (voice_files, без предела качества)
voices: РЕФ 2 на диске и файл компиляции готов
   → копия РЕФ 2 в <папка разбора>/<ключ>/  → conform.reverse партией по компиляции
   → видео разбора (out_path, доля из компиляции)
voices: озвучки → conform.submit с ref = видео разбора → дорожки
downloads.pack: видео разбора + его звук + дорожки → контейнер под именем РЕФ 2
уборка: файл компиляции — когда его не читает ни разбор, ни озвучка; видео разбора — после упаковки
```

Компиляция в план `media_items` не входит (как сейчас: `redundant`). Её файл — рабочий файл `voices`, как видео
компиляции у озвучек. Серия играет на каждом шаге: до упаковки в библиотеке лежит РЕФ 2.

## 6. Изменения по модулям

| Где | Что |
|---|---|
| `core/contracts` | `Reference.compilation` (источник, строка, плеер, группа, высота, диапазон); уровень «компиляция»; рычаги `compilation.member`, `compilation.off`; тело и итог разбора |
| `scan/reference.py` | членство серии и РЕФ 1 по разделу 3 |
| `composition` | уровень «компиляция» в наследовании рычагов и в `composition.get` (список компиляций сезона с членством серий); очереди уровня компиляции |
| `voices` | таблица разборов (миграция 0050), жизненный цикл разбора, партия по компиляции, файл компиляции без предела качества, журнал уборки и обязательства как у задач озвучек, очистка очереди (Р-75) для задач разбора; озвучки серии с РЕФ 1 ждут видео разбора |
| `conform` | запрос `conform.reverse`; итог задачи `reverse` в `conform.job.finished` (`out_path`, `from_ref_s`, `from_dub_s`); вид задачи в окне «Агенты»; ключ задачи — имя папки серии |
| `downloads/packing.py` | видео слота: видео разбора, либо контейнер, собранный с ним (метка видео), либо РЕФ 2 |
| `gateway` | событие разбора в SSE |
| `web` | режим «Компиляции» (блок сезона на компиляцию), вкладки «Компиляции» и «РЕФ 2» раскрытой серии, настройки компиляции, обводка в режиме «Карточки», источник видео в строке референса вкладки «Дорожки»; ключи `ru.ts`; токены цвета обводки и страница `/#card-colors` |

## 7. Состояния разбора

| Состояние | Когда |
|---|---|
| запланирован | РЕФ 1 выбран, работы ещё нет |
| загрузка | качается файл компиляции |
| в очереди на разбор | задача у демона ждёт |
| разбор | задача выполняется |
| готово | видео разбора есть; показывается доля из компиляции |
| ошибка | разбор не удался; кнопка «Повторить»; референс — РЕФ 2 |
| нет РЕФ 2 | у серии нет одиночной серии для разбора |

## 8. Интерфейс

| Место | Вид |
|---|---|
| Переключатель вида | третий режим «Компиляции» рядом с «Карточками» и «Плитками» |
| Блок компиляции | копия блока сезона: шапка (источник, плеер, разрешение, число серий), счётчики «Серии» (взято из всех) и «Разбор», кнопка «Настройки компиляции», выключатель всей компиляции; внутри — карточки всех охваченных серий |
| Карточка в блоке | выключатель = серия берётся из этой компиляции; цвет — состояние разбора; у невзятой серии — где она стоит: «в 660–667», «свой 2160p» |
| Раскрытая серия | вкладка «Компиляции»: все компиляции, охватывающие серию, с выключателем (включён один), разбором и долей из компиляции; вкладка «РЕФ 2»: очередь отдельных серий с меткой уровня («из компиляции») |
| Настройки компиляции | окно как у сезона: «Серии» (счётчики разбора, «Повторить все с ошибкой», «Разобрать заново»), «РЕФ 2» (порядок на весь набор) |
| Режим «Карточки» и «Плитки» | обводка за сериями, взятыми из компиляции |
| Цвет и буква | у каждой компиляции сезона — цвет из набора 16 (дальше по кругу, по порядку начала диапазона) и буква; буква в углу карточки перед выключателем; обводка и её фон — цвета компиляции; цвета — токены `--compilation-1…16` на странице `/#card-colors` |
| Обводка | собирается из ячеек сетки по каждой компиляции: скругления везде, включая внутренние углы; мост между соседями по строке и столбцу; заливка перекрёстка у квадрата 2×2; непрерывная линия между соседями по диагонали; соседние компиляции не сливаются (каждая занимает свою половину промежутка); несоприкасающиеся части одной компиляции — отдельные контуры того же цвета |

Блок компиляции — тот же компонент, что блок сезона; обводка рисуется по геометрии сетки (`ResizeObserver`, без порогов
ширины).

## 9. Проверка

| Что | Чем |
|---|---|
| Членство и выбор | перебор сочетаний: высоты, охват, пересекающиеся компиляции, выбор пользователя, выключенная компиляция, нет РЕФ 2, неудачный разбор |
| Жизненный цикл разбора | тесты модуля `voices` с имитатором демона: партия, перезапуск, отмена, уборка, очистка очереди |
| Упаковка | видео разбора в контейнере, перепаковка при смене РЕФ 1 ↔ РЕФ 2 без конформа |
| Интерфейс | тесты компонентов; шкала ширин для обводки |
| Живая проверка | одна серия с компиляцией выше одиночных. На проде такой сейчас нет: у сериала 54 компиляции 1080p и одиночные 1080p |
