# Этап 12 — компиляция как референс: устройство

Состояние: проект на согласовании, 2026-11-07. ТЗ дословно — [ЭТАП_12.md](ЭТАП_12.md).

## 1. Термины

| Термин | Значение |
|---|---|
| Компиляция | строка раскладки, у которой одно видео охватывает несколько серий (`episode_end > episode_start`) |
| РЕФ 1 | компиляция, выбранная референсом серии |
| РЕФ 2 | одиночная серия, по которой демон находит серию внутри компиляции; без компиляции она сама референс |
| Разбор | задача демона вида `reverse`: компиляция + РЕФ 2 → видео серии из компиляции на шкале времени РЕФ 2 |

## 2. Демон: разбор компиляции (контракт проверен на живом демоне 2026-11-07)

| Что | Факт |
|---|---|
| Постановка | `POST /conform/reverse` {`compilation`, `episodes[]`, `extend_edges` = true, `out_dir`, `keep_tmp`, `label`, `audio_method`, `drift_speed_pct`, `autostart`, `ref_atrack`, `dub_atracks`} → список задач, по одной на серию |
| Кэш | компиляция готовится один раз на партию, в кэше папки `out_dir`; партии с одной `out_dir` делят его |
| Результат | `<out_dir>/<папка серии>/<серия>.mkv` — видео на шкале серии: картинка и звук компиляции там, где они совпали с серией |
| Края | `extend_edges` = true: начало и конец, которых нет в компиляции, берутся из самой серии; false: результат обрезан по компиляции |
| Имя задачи | `label` задачи разбора = имя папки серии |
| Итог пары | `ok`, `out_path`, `from_ref_s` (секунд из компиляции), `from_dub_s` (секунд из серии), `suspect`, `critical`, `warnings`, `error`; `assigned_pct` для разбора не мера |
| Вид задачи | `ConformJob.kind`: `episode` (озвучки на референс) или `reverse` (разбор) |
| Просмотр каталога | `GET /conform/reverse/scan?episodes=…&out_dir=…` — серии каталога, файл каждой, готов ли результат |

## 3. Правило выбора (чистая функция `scan/reference.py`)

1. РЕФ 2 — одиночный референс по действующему правилу: очередь «РЕФ», рычаги `reference.order` и `reference.allow`, переход
   к следующему видео при неудачной загрузке.
2. Кандидаты РЕФ 1 — играющие строки-компиляции, охватывающие серию и не снятые рычагом `compilation.allow`, в очереди
   `compilation`: сначала порядок пользователя (`compilation.order`), затем высота, порядок плееров, порядок источников
   (`core.variant_queue`).
3. РЕФ 1 берётся, если его высота строго больше высоты РЕФ 2. При равной или меньшей высоте референс — РЕФ 2.
4. Нет РЕФ 2 — разбирать не по чему: серия остаётся `unfit`, как сейчас.
5. Разбор не удался — берётся следующая компиляция очереди, иначе референсом остаётся РЕФ 2 с причиной
   (правило ЭТАП_10 «не скачалось — следующий источник»).

Рычаги `compilation.allow` и `compilation.order` — отдельные от рычагов РЕФ: у одного варианта (группа, источник, плеер)
бывают и одиночные строки, и компиляции (канал VK). Уровни — сериал, сезон, серия, как у остальных рычагов.

## 4. Тождество видео и дорожки

| Положение | Следствие |
|---|---|
| Разбор с `extend_edges` = true даёт видео на шкале РЕФ 2 той же длительности | тождество видео разбора = тождество РЕФ 2 (`core.container.identity`: источник и строка) — то же правило, что для другого разрешения того же видео (ЭТАП_11, п. 5) |
| Дорожки выровнены по РЕФ 2 | годны для видео разбора; смена РЕФ 1 ↔ РЕФ 2 — перепаковка без конформа |
| Смена РЕФ 2 | другое тождество: дорожки делаются заново (этап 8) |
| Новая серия | сначала разбор, затем конформ озвучек по видео разбора |

## 5. Поток работ серии (один прогон синхронизации)

```
скан ── выбор: РЕФ 2 + РЕФ 1 ──┬── downloads: РЕФ 2 в библиотеку (как сейчас, in_plan_single)
                               └── voices: файл компиляции (voice_files, без предела качества)
voices: РЕФ 2 на диске и файл компиляции готов
   → копия РЕФ 2 в <папка разбора>/<ключ>/  → conform.reverse партией по компиляции
   → видео разбора (out_path, доля из компиляции)
voices: озвучки → conform.submit с ref = видео разбора → дорожки
downloads.pack: видео разбора + его звук + дорожки → контейнер под именем РЕФ 2
уборка: файл компиляции — когда его не читает ни разбор, ни озвучка; видео разбора — после упаковки
```

Компиляция в план `media_items` не входит (как сейчас: `redundant`). Её файл — рабочий файл `voices`, как видео
компиляции у озвучек. Серия играет на каждом шаге: до упаковки в библиотеке лежит РЕФ 2.

## 6. Изменения по модулям

| Где | Что |
|---|---|
| `core/contracts` | `Reference.compilation` (источник, строка, плеер, группа, высота, диапазон); рычаги `compilation.allow`, `compilation.order`; очередь `compilation` в `QueuesReply`; тело и итог разбора |
| `scan/reference.py` | выбор РЕФ 1 по разделу 3 |
| `composition/queues.py` | очередь компиляций уровня |
| `voices` | таблица разборов (миграция 0050), жизненный цикл разбора, партия по компиляции, файл компиляции без предела качества, журнал уборки и обязательства как у задач озвучек, очистка очереди (Р-75) для задач разбора; озвучки серии с РЕФ 1 ждут видео разбора |
| `conform` | запрос `conform.reverse`; итог задачи `reverse` в `conform.job.finished` (`out_path`, `from_ref_s`, `from_dub_s`); вид задачи в окне «Агенты»; ключ задачи — имя папки серии |
| `downloads/packing.py` | видео слота: видео разбора, либо контейнер, собранный с ним (метка видео), либо РЕФ 2 |
| `gateway` | событие разбора в SSE |
| `web` | обводка компиляции за карточками и плитками; таблица «РЕФ 1» над очередью «РЕФ 2» во вкладке «РЕФ»; источник видео в строке референса вкладки «Дорожки»; ключи `ru.ts`; токены цвета обводки и страница `/#card-colors` |

## 7. Состояния разбора

| Состояние | Когда |
|---|---|
| запланирован | РЕФ 1 выбран, работы ещё нет |
| загрузка | качается файл компиляции |
| в очереди на разбор | задача у демона ждёт |
| разбор | задача выполняется |
| готово | видео разбора есть; показывается доля из компиляции |
| ошибка | разбор не удался; кнопка «Повторить»; референс — следующая компиляция или РЕФ 2 |
| нет РЕФ 2 | у серии нет одиночной серии для разбора |

## 8. Интерфейс

| Место | Вид |
|---|---|
| Карточки и плитки сезона | обводка с заливкой за сериями, которые охватывает выбранный РЕФ 1; контур идёт по потоку сетки и переламывается на переносе строки; две соседние компиляции — два контура |
| Карточка серии | источник и разрешение РЕФ 1 |
| Вкладка «РЕФ» | таблица «РЕФ 1» (Брать, порядок, Источник, Плеер, Разрешение, Группа озвучки, Серии, Разбор, Из компиляции, метка) над очередью «РЕФ 2» (нынешняя очередь референса) |
| Вкладка «Дорожки» | у дорожки-референса «Откуда»: источник, разрешение и диапазон компиляции |

Обводка рисуется по геометрии сетки (`ResizeObserver`, без порогов ширины).

## 9. Проверка

| Что | Чем |
|---|---|
| Выбор РЕФ 1 и РЕФ 2 | перебор сочетаний: высоты, рычаги, пересекающиеся компиляции, нет РЕФ 2, неудачный разбор |
| Жизненный цикл разбора | тесты модуля `voices` с имитатором демона: партия, перезапуск, отмена, уборка, очистка очереди |
| Упаковка | видео разбора в контейнере, перепаковка при смене РЕФ 1 ↔ РЕФ 2 без конформа |
| Интерфейс | тесты компонентов; шкала ширин для обводки |
| Живая проверка | одна серия с компиляцией выше одиночных. На проде такой сейчас нет: у сериала 54 компиляции 1080p и одиночные 1080p |

## 10. На решение владельца

| № | Вопрос | Предложение |
|---|---|---|
| 1 | Дорожки, уже выровненные по РЕФ 2, при появлении РЕФ 1 | не переделывать: видео разбора на той же шкале (раздел 4) |
| 2 | Края серии берутся из РЕФ 2 вместе со звуком; у РЕФ 2 другой озвучки на краях звучит она | при выбранном РЕФ 1 ставить в очереди РЕФ 2 первыми одиночные серии той же группы озвучки, что и компиляция |
| 3 | Сериал для живой проверки | назначает владелец |
