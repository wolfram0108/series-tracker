# Словарь интерфейса: опись названий

Дата: 2026-11-12. Состояние: **утверждён владельцем 2026-11-12**. Единственный источник
названий: экраны берут слова, значки и цвета состояний только из него — слова из каталога
`web/src/i18n/ru.ts` (`state.*`), значки и таблицы кодов модулей из `web/src/lib/states.ts`,
цвета из `web/src/styles/tokens.css` (`--state-*`).

Колонка «Предлагаю» — принятое название понятия.

## 1. Правила словаря

| № | Правило |
|---|---|
| П-1 | Одно понятие — одно слово во всём приложении: в карточке, таблице, подсказке, журнале, кнопке. |
| П-2 | Слово состояния не зависит от предмета: средний род («готово», «отключено», «отменено»). Сейчас одно и то же состояние склоняется по предмету: «Готов» у сериала, «готово» у серии, «готова» у дорожки. |
| П-3 | В каталоге одна запись слова, со строчной. С заглавной слово пишется только в отдельной подписи (пилюля, заголовок): экран поднимает первую букву сам. |
| П-4 | Идущая работа называется своим процессом: «загрузка», «выравнивание», «упаковка». Общие слова «обработка» и «выполняется» не применяются. |
| П-5 | Каждое состояние несёт в словаре слово, значок и цвет. Экран не подбирает свои. |
| П-6 | Одно действие — один глагол. Разные действия — разные глаголы, даже когда кнопки похожи. |
| П-7 | Текста, видимого пользователю, в коде экрана нет: только ключ каталога. |
